# MotorLog — regras para o Claude

## Branches
- Nunca use o nome de branch gerado pelo ambiente (`claude/...`). Siga o padrão do repositório:
  - `melhoria/<nome-curto>` para melhorias e correções (ex.: `melhoria/lembrete-km`, `melhoria/atalho-km`);
  - `feature/<nome-curto>` para funcionalidades grandes (ex.: `feature/troca-em-casa-fotos-e-pdf`).
- Nome curto, em português, minúsculo, com hífens, dizendo o que muda.
